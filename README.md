# UBCx: How to Code — Simple Data

Lecture notes and solutions to every problem in **UBCx *How to Code: Simple Data*** (edX), the first course in UBC's *Systematic Program Design* series. It is taught in Racket (Beginning Student Language) using the *How to Design Programs* recipe.

## Modules

| # | Module | Folder |
|---|---|---|
| 1a | Beginning Student Language | `beginning-student-language/` |
| 1b | How to Design Functions | `how-to-design-functions/` |
| 2 | How to Design Data | `how-to-design-data/` |
| 3a | How to Design Worlds (interactive programs with `big-bang`) | `how-to-design-worlds/` |
| 3b | Compound Data | `compound-data/` |
| 4 | Self-Reference (lists and recursive data) | `self-reference/` |
| 5 | Naturals and Helpers | `naturals/`, `helpers/` |
| 6 | Binary Search Trees | `binary_search_trees/` |

`practice-problems/` holds about 100 solved exercises from across the course.

## Running

Open any `.rkt` file in [DrRacket](https://racket-lang.org/) with the language set to the appropriate *How to Design Programs* student language.
